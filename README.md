# AI Sana — каталог практических бизнес-задач

MVP по кейсу HackAlem AI. Бизнес описывает задачу, дополняет карточку и подтверждает её; команды просматривают каталог и отправляют предложения; бизнес вручную принимает решение по откликам.

## Стек

- Next.js App Router и TypeScript
- На этапе демо данные хранятся в браузере (`localStorage`); отдельной базы пока нет. При первом запуске добавляются синтетические примеры задач, команд и откликов; существующие данные не затираются.
- `POST /api/clarify` содержит детерминированную заглушку для шага уточнения. Подключение внешнего AI-провайдера — следующий этап; API-ключ нельзя помещать в браузер или Git

## Запуск

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Для переменных окружения скопируйте `.env.example` в `.env.local`; реальные секреты не коммитьте.

## Структура

```text
src/
  app/                         страницы и API маршруты
    api/clarify/route.ts       уточняющие вопросы, сейчас fallback
    business/new/              конструктор бизнес-задачи
    business/tasks/[taskId]/responses/  экран решений по откликам
    catalog/                   общий каталог
  features/
    tasks/                     типы задачи и формула рейтинга
    proposals/                 форма отклика и ручное решение бизнеса
  lib/                         общее localStorage-хранилище и подписка на изменения
```

## Сквозные маршруты откликов

- Команда подаёт отклик: `/catalog/{taskId}/respond`.
- Бизнес принимает решение: `/business/tasks/{taskId}/responses`.
- Для связи экранов используйте общий `taskId`. Функции `saveTask`, `saveTeams` и `createProposal` находятся в `src/lib/storage.ts`; изменения обновляют открытые экраны в той же вкладке и между вкладками одного браузера.
- Выбор одного отклика не назначает остальные автоматически: бизнес может выбрать несколько предложений или ни одного.

## Роли разработки

- Участник 1: черновик, уточнение, редактирование и подтверждение карточки.
- Участник 2: рейтинг, уровни готовности, подсказки, фильтры и сортировка каталога.
- Участник 3: форма отклика, решения бизнеса и интеграция сценария.

## MVP-правила

- Рейтинг задачи: контекст и потребность — 20; данные — 20; ожидаемый результат — 15; критерии успеха — 15; ограничения — 10; пользователи — 10; связь с бизнесом — 10 баллов.
- Уровни: 0–39 — черновик; 40–69 — рабочая; 70–89 — готовая; 90–100 — приоритетная.
- Каталог не скрывает задачи с низким рейтингом. Сортировка и фильтры помогают их сравнивать.
- Команды подают отклики самостоятельно. Решение о выборе или отказе принимает бизнес вручную.
- Текст, предложенный AI, должен быть проверен и подтверждён человеком; AI не добавляет неподтверждённые факты.
